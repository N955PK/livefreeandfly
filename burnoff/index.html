THE TODAY TIMELINE

One bar, 05:00–22:30 Pacific (airport-local) time — all times on this page are. Grey = when a deck (ceiling < 3,000 ft) has actually been observed over the field so far today. Lighter grey = hours where the model expects a deck from now on (HRRR low-cloud ≥ 50%) — same substance as observed, fainter certainty. Prediction windows: green box = clearing (good), amber box = fog returning, each a best-time marker inside an empirical ± band. Red is reserved for fog itself. Dashed verticals are sunrise and sunset; the white line is now, and it moves.

THE FOUR ESTIMATORS

CLARO — our fitted model (Ceiling Lift And Return Outlook): ridge regressions for burn-off and return time plus a logistic model for hourly P(ceiling < 1,000 ft), trained in your browser on three warm seasons (Apr–Oct) of archived METARs, 05:00 SFO→SAC / SFO→RNO pressure gradients, HRRR archive fields, and T850−T2m as an inversion-strength proxy — the marine layer is capped near 850 hPa, and inversion structure governs stratus (Iacobellis & Cayan 2013). Architecture follows the KSFO stratus systems (Hilliker & Fritsch 1999; MIT-LL Marine Stratus Forecast System). HRRR — NOAA's 3-km hourly-refresh model, read directly: first hour under 40% low cloud = clears; first over 60% = returns. Recent days — medians of what actually happened, last 7 days. Gradient — live SFO→SAC onshore push: stronger push, deeper deck, later burn-off, earlier evening return.

How fog/time works

This page predicts, per airport, when today's marine-layer deck burns off, when it returns, and the hour-by-hour probability the ceiling is below 1,000 ft — and it shows you exactly how it earns those numbers.

LIVE DATA

Latest observation comes from the National Weather Service feed and refreshes every 5 minutes (plus instantly when you return to the tab). The big colored line is the decoded METAR — lowest ceiling layer and visibility — with its exact observation time and a live age counter; tap it for the raw METAR string. Because some AWOS feeds ship empty structured fields, ceilings are also parsed straight from the raw text (BKN/OVC/VV groups), so fields like WVI read correctly.

EVENT DEFINITIONS

A deck is a ceiling under 3,000 ft (the operational stratus threshold used at SFO). A burn-off is the first post-sunrise lift that holds 60+ minutes. A return is the first re-deck that holds 45+ minutes and comes after a genuine burn-off — a day that never cleared has no return, by definition, and momentary blips count as neither. The same state machine judges observations and models, so comparisons are apples-to-apples.

THE FOUR ESTIMATORS

CLARO — the fitted model (below). HRRR — NOAA's 3-km hourly-refresh model: first hour under 40% low cloud = clears; first hour over 60% = returns. Recent days — medians of the observed events over the past week. Gradient — live SFO→SAC and SFO→RNO sea-level-pressure differences: onshore push deepens the layer (roughly +18 min later clearing and −14 min earlier return per hPa above +2.0 in the fallback blend), with the 12-hour trend as a modifier.

CLARO — THE FITTED MODEL

CLARO (Ceiling Lift And Return Outlook) trains in your browser on three warm seasons (Apr–Oct) of archived METARs, then refits daily with a light top-up. Features, each with a physical reason: dawn ceiling height (the deck base proxies the inversion base, which governs stratus extent — Iacobellis & Cayan 2013); T850−T2m (inversion strength — the marine layer is capped near 850 hPa; cf. Klein–Hartmann lower-tropospheric stability); SFO→SAC / SFO→RNO gradients + overnight trend (synoptic onshore push); HRRR's own clearing time (the regression learns how much to trust the model); yesterday's clearing (regime persistence); and day-of-year harmonics (solar forcing). Burn-off and return are ridge regressions; P(<1000 ft) is a logistic model. The architecture follows the KSFO stratus lineage — Hilliker & Fritsch 1999 and the MIT-Lincoln-Lab Marine Stratus Forecast System's consensus-of-models design.

VERIFICATION — WHY YOU CAN TRUST (OR DISTRUST) IT

Every score is walk-forward: for each of the last 45 event-days, CLARO refits on strictly earlier days only, then predicts blind. Mean absolute error is reported against three baselines — raw HRRR, persistence, and the 7-day median — plus median bias, return-time MAE, and a Brier Skill Score for the <1000 ft probabilities. The ± band on every headline is the 80th percentile of CLARO's own blind errors — an empirical interval, not an assumption. All numbers, and the standardized coefficients per field, live in the CLARO — Methods & Verification drawer at the bottom of the page.

LIMITS

Warm-season model — winter tule fog is different physics. T850 comes from a coarse model, not soundings. AWOS archives have gaps. Small verification samples wobble. Experimental — never a substitute for an official briefing.
